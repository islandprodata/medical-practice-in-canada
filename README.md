## Fields

| Column | Description | Example |
|---|---|---|
| `country` | Country (all rows: `canada`) | `canada` |
| `founded` | Year founded (may be empty) | `1979` |
| `id` | Opaque source record ID | `RWXrNwr7fFGnW5YTJns7VAppOMmn` |
| `industry` | Industry (all rows: `medical practice`) | `medical practice` |
| `linkedin_url` | LinkedIn company page (domain + path) | `linkedin.com/company/york-med-systems-inc.` |
| `locality` | City / town | `richmond hill` |
| `name` | Company name | `york-med systems inc.` |
| `region` | State / region (lowercase) | `ontario` |
| `size` | Employee-count band | `1-10` |
| `website` | Company website domain (may be empty) | `york-med.com` |

**Notes:**
- `founded` and `website` are empty for some records.
- `size` values look like `1-10`, `11-50`, `51-200`, etc.
- CSV is UTF-8 with a header row; fields with commas are quoted.
